Django Todo App - Complete DevOps CI/CD Pipeline

*A comprehensive demonstration of modern DevOps practices with Docker, Jenkins, and AWS deployment*

## 🎯 Project Overview

This project demonstrates a complete **end-to-end DevOps pipeline** for a Django Todo application, showcasing:

- ✅ Local development with virtual environments
- 🐳 Docker containerization for consistent deployments  
- ☁️ AWS EC2 cloud infrastructure setup
- 🔄 Jenkins CI/CD automation
- 🎼 Docker Compose orchestration
- 🚀 Automated build and deployment workflows


A practical project demonstrating how I built and deployed a Django Todo App with a complete DevOps CI/CD pipeline using Docker, Jenkins, and AWS for automated deployment.
