# 📝 Django Todo App – End-to-End DevOps Deployment on AWS

A production-grade DevOps pipeline project that automates the deployment of a Django-based Todo application using **AWS EC2**, **Jenkins**, **Docker**, and **GitHub Actions**. This project showcases real-world DevOps practices, from infrastructure setup to CI/CD pipelines.

## 🚀 Project Overview

This project demonstrates how to:
- Build a Django web application
- Deploy it manually on AWS EC2
- Containerize it using Docker
- Automate deployment using Jenkins
- Integrate GitHub for CI/CD pipelines

---

## 🧰 Tech Stack

| Tool | Purpose |
|------|---------|
| **Django** | Python Web Framework |
| **Docker** | Containerization |
| **Docker Compose** | Multi-container setup |
| **AWS EC2** | Server to host application |
| **Jenkins** | CI/CD automation |
| **GitHub** | Source code management |
| **GitHub PAT** | GitHub-Jenkins integration |
| **AWS Security Groups** | Network traffic control |
